# Task Status Definitions

| Status | Qualifies when | Not when |
|---|---|---|
| Not Started | Work hasn't begun | - |
| In Progress | Owner actively working | Paused waiting for someone else |
| Blocked | Can't proceed due to a specific unresolved dependency/problem | Just busy or slow |
| Waiting | Ready but waiting on an input; prep may continue | - |
| At Risk | Likely to miss its due date | Merely close to its due date |
| Done | Deliverable complete, delivered where needed, and any required review/approval finished | "Almost done", "should be done tomorrow", "done, just needs review", "I sent it" (unverified) |

Status changes to the official record always need approval.
