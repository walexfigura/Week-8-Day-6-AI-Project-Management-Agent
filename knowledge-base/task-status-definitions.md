# Task Status Definitions

| Status | Qualifies when | Does **not** qualify |
|---|---|---|
| **Not Started** | Work hasn't begun; may be waiting for its start window | - |
| **In Progress** | The owner is actively working on it | Work paused waiting for someone else (that's Blocked/Waiting) |
| **Blocked** | Can't proceed because of a specific unresolved dependency or problem | Just slow or busy |
| **Waiting** | Ready to proceed but waiting on an input from another task or person; partial prep may continue | - |
| **At Risk** | Still possible, but the owner or the projection says the due date is likely to be missed | Merely close to its due date with no sign of slipping |
| **Done** | The deliverable is complete, delivered to where it is needed, and any required review/approval is finished | "Almost finished", "should be done tomorrow", "done, just needs review", "I sent it" (unverified) |

## Rules
- A task is never marked Done because the owner *expects* to finish. "Done, just needs review" stays In Progress, with a note, until the review completes.
- "I sent this yesterday" is a delivery **claim**. Verify (link, recipient confirmation, or file on the task) before treating it as delivered.
- Status changes on the official board always go through approval.
